What this app is

This app enables Hermes, the personal AI assistant of Christopher Baek, to access Google Workspace services on behalf of its sole authorized user — Christopher Baek. It is a single-user application and does not collect data from any other person.

Data accessed

With the user's explicit OAuth consent, this app may access:

  • Gmail — to read, search, and send email at the user's request
  • Calendar — to list and manage events at the user's request
  • Drive, Sheets, and Docs — to search, read, and manage the user's own files at the user's request
  • Contacts — to look up addresses at the user's request

How data is used

Data retrieved from Google services is used only to fulfill the user's own requests. It is processed on the user's own computer and instantaneous needs, and is not sold, rented, shared, or disclosed to any third party. The app does not run any analytics or advertising.

Data storage

OAuth tokens are stored locally, solely on the user's own computer. The operator of this app is the same person whose data is accessed; there is no separate data controller.

Data removal

The user may revoke the app's access at any time at myaccount.google.com/permissions, and may delete any local data at will.
